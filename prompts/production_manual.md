I have uploaded several documents related to a USDOT BUILD Benefit-Cost Analysis (BCA).

These documents include:

• USDOT Benefit-Cost Analysis Guidance (official methodology)
• USDOT BCA Excel Template
• Example BCA Technical Memorandum
• Example BCA Workbook
• Howard County BUILD Application (project being analyzed)
• Howard County Risk and Resilience Analysis Materials

You are a senior transportation economist and infrastructure finance consultant with extensive experience preparing USDOT BUILD, RAISE, INFRA, MEGA, CRISI, BIP, and other discretionary grant BCAs.

Your objective is to prepare a professional-quality USDOT Benefit-Cost Analysis package for the Howard County Marriottsville Road and Bridge Improvement Project.

---

## GOVERNING RULES

1. Follow the uploaded USDOT Benefit-Cost Analysis Guidance as the governing methodology.

2. Use the uploaded example BCA memorandum and example workbook as professional references for:
   • document organization
   • section hierarchy
   • workbook structure
   • table formats
   • calculation presentation
   • summary reporting
   • sensitivity analysis
   • level of technical detail

3. Use the uploaded Howard County project documents as the primary source of project information.

4. Do not simply summarize the documents.

5. Build a complete BCA package as though it were being submitted to USDOT economists for grant evaluation.

6. Use professional engineering and economic judgment where necessary.

7. Avoid double-counting benefits.

8. Clearly distinguish between:
   • monetized benefits
   • quantified but non-monetized benefits
   • qualitative benefits

9. Do not count the following as monetized BCA benefits unless explicitly allowed under the USDOT guidance:
   • jobs created
   • economic multipliers
   • GDP impacts
   • property value increases
   • tax revenue increases
   • tourism spending
   • housing development impacts
   • economic development impacts

10. If assumptions are required, clearly state them and explain the basis for each assumption.

11. The objective is not to copy the example project. The objective is to produce deliverables that look and read as though they were prepared by the same consulting team using the same professional standards and methodology.

12. Ensure that the workbook is reproducible. The workbook should contain live formulas for traffic growth, crash reductions, travel time savings, discounting, NPV, and BCR. Instead, most results are typed numbers.

## PHASE 1 – PROJECT ASSESSMENT

Before preparing the BCA, conduct a project assessment.

Identify:

1. Which benefit categories appear appropriate for this project.

2. Which benefit categories are directly supported by project information.

3. Which benefit categories are potentially supportable using reasonable assumptions.

4. Which benefit categories should NOT be included under USDOT guidance.

5. The likely primary drivers of the project's Benefit-Cost Ratio.

6. The likely strongest and weakest portions of the future BCA.

Provide a concise professional assessment before proceeding.

## PHASE 4 – PERFORM THE BENEFIT-COST ANALYSIS

Using the project documents, USDOT guidance, and reasonable professional assumptions where necessary:

1. Identify all applicable benefit categories.

2. Estimate benefits.

3. Estimate costs.

4. Estimate O&M impacts.

5. Estimate residual value if appropriate.

6. Apply inflation adjustments consistent with USDOT guidance.

7. Apply discounting consistent with USDOT guidance.

8. Calculate:

   • Present Value Benefits
   • Present Value Costs
   • Net Present Value (NPV)
   • Benefit-Cost Ratio (BCR)

For every calculation:

• Show formulas
• Show assumptions
• Show intermediate calculations
• Show methodology
• Explain how values were derived

Do not skip calculation steps.
